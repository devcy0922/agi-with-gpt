# Repository Analyst Skill

## Overview
Target Repository(Promptia, PDF validator, GoVail 등)의 코드베이스 구조, 의존성, 빌드 테스트 환경을 신속하게 파악하고 세션 작성의 기초 자료를 조사하는 스킬입니다.

## Checklist
- [ ] Target Repo 위치 파악 (`~/srv/<target-repo>`)
- [ ] 주요 엔트리포인트 및 설정 파일 (`package.json`, `Cargo.toml`, `pyproject.toml` 등) 확인
- [ ] 빌드 및 테스트 명령 확인
- [ ] 연관 파일 모듈 관계 파악
- [ ] 보안 침해 요소 (`.env`, `192.168.x.x`, 시크릿) 존재 여부 사전 점검
